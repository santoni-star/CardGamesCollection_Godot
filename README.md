# Card Games Collection (Godot 4.3)

## Як відкрити
1. Встановіть Godot 4.3+ (godotengine.org, безкоштовно).
2. Godot → Import → виберіть файл `project.godot` у цій папці.
3. Натисніть F5 (Run) — стартова сцена: `scenes/MainMenu.tscn`.

## Що вже працює
- **Головне меню** з переходом до трьох ігор + налаштування.
- **Settings**: гучність звуку/музики, ім'я гравця — зберігається в `user://savegame.dat`.

### Спільне анімаційне ядро (движок)
`scripts/core/CardFX.gd` — єдине місце з усіма tween-анімаціями (поява карти, переворот,
рух, "збирання" взятки до переможця, тремтіння при нелегальному ході, пульсація при
важливій події). **Жодна гра не пише власний код анімацій** — Blackjack, Тисяча і Hearts
просто викликають `card_view.animate_in()`, `card_view.animate_flip_to(...)`,
`card_view.animate_collect(direction)` тощо. Це і є той "движок + модулі-правила", про
який питали: щоб додати нову гру, потрібно написати тільки її правила (`scripts/games/NewGame.gd`)
і розкладку столу (`.tscn`) — весь візуальний "почерк" (як карти з'являються, перевертаються,
збираються) успадковується автоматично через CardFX, CardView і HandCard.

- **Спільна архітектура карт**: `Card.gd` (масть/ранг/значення для різних ігор, включно
  зі стандартним порядком "туз старший" для Hearts і спеціальним порядком для Тисячі),
  `Deck.gd` (стандартна колода 52 карти + скорочена 24-карткова для Тисячі),
  `CardView.gd/.tscn` + `HandCard.gd/.tscn` (візуал карти без потреби у зовнішньому арті,
  обидва вміють анімуватись через CardFX).

- **Blackjack (21)** — повністю грабельна гра:
  - ставки фішками, роздача карт по одній з анімацією, Hit / Stand / Double Down
  - переворот закритої карти дилера — анімований flip, а не миттєва зміна
  - Blackjack (виплата 3:2), push, бюст
  - ІІ дилера (бере карти до 17, зупиняється на 17+)
  - фішки зберігаються між сесіями, автоматичний ресет на 500 при нулі

- **Thousand (1000)** — повністю грабельна гра проти 2 ІІ:
  - торги (крок +5/+25, мінімум 100), прикуп із 3 карт віддається переможцю торгів
  - скидання 3 карт після прикупу (клік по картах для вибору)
  - шлюби (King+Queen однієї масті) при виході з них — перший оголошений шлюб визначає козир,
    вартість: ♥100 / ♦80 / ♣60 / ♠40 (з пульсацією при оголошенні)
  - взятки з правилом "ходити в масть", козир б'є все, порядок 9<J<Q<K<10<A
  - виграна взятка візуально "збирається" й летить до переможця перед зникненням
  - рахунок гравців окремо від тих, хто взяв контракт; гра до 1000 очок
  - ІІ оцінює силу руки, торгується, скидає найслабші карти, намагається виграти дешевими картами
    або "скинути" низькі очки, якщо взятку не виграти
  - **Спрощення відносно турнірних правил**: немає штрафної зони "бочка" (880-1000),
    шлюб завжди оголошується автоматично при виході з нього, немає обов'язкового перебиття
    козирем при відсутності масті, крок ставки фіксований (+5/+25 замість вільного).

- **Hearts** — повністю грабельна гра проти 3 ІІ (You/West/North/East):
  - обмін картами перед роздачею: ліворуч → праворуч → навхрест → без обміну (цикл по 4 раунди)
  - хід 2♣ завжди першим, обмеження першої взятки (не можна скидати черви/Q♠, якщо є безпечна карта)
  - "серце не розкрите" — не можна ходити з червів, поки їх не скинули вимушено
  - Q♠ = 13 штрафних очок, кожна черва = 1; гра до 100, виграє МІНІМАЛЬНИЙ рахунок
  - "вистріл місяцем" — хто забрав усі 26 штрафних очок за роздачу, той отримує 0,
    а решта +26 кожному
  - ІІ оцінює "небезпечність" карт (Q♠ > черви > старші піки) для обміну та скидання
  - **Спрощення**: першотрюкове обмеження застосовується тільки коли гравець без масті
    ходу і має безпечну альтернативу (на практиці збігається з повними правилами,
    оскільки лідер завжди змушений відкривати 2♣).

## Наступні кроки (roadmap)
1. Заміна текстових карт на справжню графіку (спрайти замість Label/ColorRect) —
   CardFX анімації одразу запрацюють і з текстурами, міняти нічого не треба.
2. Звукові ефекти (роздача, перемога/програш) — гучність вже підв'язана в Settings.
3. Локалізація (UA/EN) через Godot Translation.
4. Повністю data-driven правила (наприклад Resource-файл з параметрами гри) —
   зараз кожна гра все ще окремий .gd-скрипт, хоч і на спільному візуальному ядрі;
   винесення бідингу/обміну/трюків у спільний базовий клас — логічний наступний крок.
5. Якщо плануєте Google Play — потрібен export template Android + підпис APK/AAB,
   іконки під усі розміри, Privacy Policy (обов'язково для казино-подібних ігор
   навіть без реальних грошей).

## Структура
```
CardGames/
├── project.godot
├── scripts/
│   ├── autoload/GameData.gd      # фішки, налаштування, save/load
│   ├── core/CardFX.gd            # спільне анімаційне ядро (весь tween-код тут)
│   ├── card/Card.gd, Deck.gd     # спільна логіка карт для всіх ігор
│   ├── ui/                       # MainMenu, Settings, CardView, HandCard
│   └── games/                    # Blackjack, Thousand, Hearts — усі готові
└── scenes/
    ├── MainMenu.tscn, Settings.tscn
    ├── components/{CardView,HandCard}.tscn
    └── games/{Blackjack,Thousand,Hearts}/
```
