# Card Games Collection (Godot 4.7)

Збірник карткових ігор на спільному анімаційному ядрі. Чотири гри: **Косинка**,
**Блекджек (21)**, **Тисяча (1000)**, **Чирви (Hearts)**.

## Як відкрити
1. Встановіть Godot 4.7 (godotengine.org, безкоштовно).
2. Godot → Import → виберіть файл `project.godot` у цій папці.
3. Натисніть F5 (Run) — стартова сцена: `scenes/MainMenu.tscn`.

> Проєкт не залежить від кешу глобальних класів (`.godot/global_script_class_cache.cfg`):
> усі типи `Card` / `CardFX` / `Deck` підключені явними `preload`-константами, тому
> працює одразу після розпаковування на будь-якій машині.

## Ігри

- **Косинка (Klondike Solitaire)** — класичний пасьянс:
  - 7 стовпців (спадні, чергування кольорів), сток → скид по 1 карті, рецикл скиду
  - 4 фундаменти A→K за мастю; клік по карті = авто-спроба на фундамент, інакше вибір групи;
    подвійний клік = швидке переміщення на фундамент; клік по вибраній карті = скасувати вибір
  - лічильник ходів і таймер, «Нова гра», перемога при 52 картах у фундаментах
  - логіка покрита headless-тестами (`tests/test_kosynka.gd`)

- **Blackjack (21)** — повністю грабельна гра:
  - ставки фішками, роздача карт по одній з анімацією, Hit / Stand / Double Down
  - переворот закритої карти дилера — анімований flip, а не миттєва зміна
  - Blackjack (виплата 3:2), push, бюст; ІІ дилера (бере до 17)
  - фішки зберігаються між сесіями, автоматичний ресет на 500 при нулі

- **Thousand (1000)** — гра проти 2 ІІ:
  - торги (крок +5/+25, мінімум 100), прикуп із 3 карт віддається переможцю торгів
  - скидання 3 карт після прикупу (клік по картах для вибору)
  - шлюби (King+Queen однієї масті) — перший оголошений шлюб визначає козир,
    вартість: ♥100 / ♦80 / ♣60 / ♠40
  - взятки з правилом «ходити в масть», козир б'є все, порядок 9<J<Q<K<10<A
  - виграна взятка візуально «збирається» й летить до переможця; гра до 1000 очок
  - ІІ оцінює силу руки, торгується, скидає найслабші карти
  - **Спрощення**: немає «бочки» (880–1000), шлюб оголошується автоматично,
    немає обов'язкового перебиття козирем, крок ставки фіксований

- **Hearts** — гра проти 3 ІІ (You/West/North/East):
  - обмін картами: ліворуч → праворуч → навхрест → без обміну (цикл по 4 раунди);
    кнопка передачі — стрілка у напрямку обміну
  - хід 2♣ завжди першим, обмеження першої взятки
  - «серце не розкрите»; Q♠ = 13 очок, черва = 1; гра до 100, виграє мінімальний рахунок
  - «вистріл місяцем» (усі 26 очок — 0 тобі, +26 іншим)
  - ІІ оцінює «небезпечність» карт (Q♠ > черви > старші піки)

## Архітектура

- **Спільне анімаційне ядро**: `scripts/core/CardFX.gd` — єдине місце з усіма
  tween-анімаціями (поява, переворот, рух, збирання взятки, тремтіння при нелегальному
  ході, пульсація). Жодна гра не пише власний код анімацій.
- **Спільна логіка карт**: `Card.gd` (масть/ранг/значення), `Deck.gd` (52 та 24 карти),
  `CardView.gd/.tscn` + `HandCard.gd/.tscn` — візуал без зовнішнього арту.
- **GameData** (autoload): фішки, гучність, ім'я гравця — `user://savegame.dat`.
- **Тести**: `tests/` — headless smoke-тести логіки (`godot --headless --path . --script tests/test_kosynka.gd`).

## Структура
```
├── project.godot
├── scripts/
│   ├── autoload/GameData.gd      # фішки, налаштування, save/load
│   ├── core/CardFX.gd            # спільне анімаційне ядро (весь tween-код тут)
│   ├── card/Card.gd, Deck.gd     # спільна логіка карт
│   ├── ui/                       # MainMenu, Settings, CardView, HandCard
│   └── games/                    # Kosynka, Blackjack, Thousand, Hearts
├── scenes/
│   ├── MainMenu.tscn, Settings.tscn
│   ├── components/{CardView,HandCard}.tscn
│   └── games/{Kosynka,Blackjack,Thousand,Hearts}/
└── tests/                        # headless-тести логіки
```
